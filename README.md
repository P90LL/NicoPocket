# NicoPocket

ニコニコ動画のAAC音声を、編集したタイトル・メタデータ・アートワーク付きのM4Aとして保存するChrome拡張機能です。[masteralice3104/nico_downloader](https://github.com/masteralice3104/nico_downloader)を基盤にしています。

**個人利用・ローカルインストール専用です。Chrome Web Storeでの公開予定はありません。**

## できること

- 動画ページから独立した編集ウィンドウを開き、保存タイトルを変更する
- 標準音質または高音質を選ぶ
- サムネイルを正方形に切り抜き、JPEGアートワークとして埋め込む
- 保存前にメタデータを確認・編集し、プリセットを利用する
- 保存状況を確認し、中断・エラー後に再試行する

最終出力はM4Aです。標準音質では192 kbps以下の音源を優先し、それがなく192 kbps超の音源を取得した場合だけAAC-LC 192 kbpsを目標に再エンコードします。高音質では最高品質の取得可能な音声をコピーします。品質が判別できない場合は既存の取得方法と音声コピーを使用します。AACやJPEGの中間ファイルはユーザー向けに保存しません。

複数サイト、一括・並列ダウンロード、キュー、MP3出力、AIによる切り抜きは対象外です。各条件の定義は[現行仕様](SPECIFICATION.md)を参照してください。

## インストールと基本操作

1. Chromeで`chrome://extensions/`を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの **`nico_downloader/`** を選択します。
3. ニコニコ動画の動画ページを開いて再生し、「NicoPocketで保存」を押します。
4. 編集ウィンドウでタイトル、音質、アートワーク、メタデータを確認します。
5. Downloadを押します。Chromeの許可や保存先確認が表示された場合は、Chrome側で操作してください。

拡張機能の更新後は、拡張機能と開いている動画ページを再読み込みしてください。各編集画面、プリセット、バックアップ、エラー時の操作は[利用ガイド](USER_GUIDE.md)を参照してください。

画面上の表示バージョンは **1.0.0（個人利用版）**、拡張機能の内部バージョンは **5.0.0.23** です。基本的なM4A保存、メタデータ、アートワーク、音質選択、連続保存、再試行などには、ユーザーによる実サイト確認の記録があります。

## 主な制限

- Chromeの許可画面や保存先ダイアログは自動操作しません。保存待ちをキャンセルして再試行できます。
- 同種のニコニコ保存系拡張機能との併用は推奨しません。追加のAAC保存などが起きた場合は、他の拡張機能を無効化し、新しい動画タブで確認してください。
- ニコニコ動画の配信方式、ページ構造、音質ID、画像ホストが変わると取得できない場合があります。
- 長時間・大容量の動画はブラウザメモリや同梱FFmpegの制約を受けます。
- アートワークはJPEGを使用します。PNGは合成環境で格納を確認しましたが、一般的なネイティブプレイヤーでの比較は未確認です。
- 編集ウィンドウを閉じると、アートワークとメタデータの編集状態は失われます。

症状別の対応は[利用ガイドの「困ったとき」](USER_GUIDE.md#困ったとき)を参照してください。

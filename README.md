# にこぽけ（NicoPocket）

ニコニコ動画の音声取得、音質調整、正方形ジャケットの生成、メタデータ付きM4A保存を目指す、個人利用向けChrome拡張機能です。`masteralice3104/nico_downloader` をフォークし、既存実装を尊重して必要な改修・独自機能の追加を行います。

> [!IMPORTANT]
> 開発中です。独立ウィンドウの入口、候補・設定管理、手動クロップを接続しています。AACを再圧縮しないM4A生成・タグ・表紙処理を追加しました。保存画面・実取得との接続と画像認識は未完了です。音質上限と取得済みHLS音声片の処理は合成入力で確認した段階に限ります。既存のnico downloaderの保存経路は維持していますが、現行サイトでの通し動作は未確認です。

## 基本方針

- 衝突する仕様も含めて `nico downloader` の既存実装を尊重し、NicoPocketの機能実現に必要な場合に改修・追加する。Cookie送信は既存の通信設定に従う。
- フォーク元の基本仕様を回帰基準とする。既定の対象URLは `sm` で始まる動画IDで、対象パターンは既存のオプションから変更できる。上流が対象外とする暗号化動画への対応を、NicoPocketの合成HLS検証から保証しない。
- デザイン・仕様は `nico-pocket-proj` で決定された内容を使用する。
- 公開する文書・ソース・成果物には、環境固有のローカルパスやセンシティブな情報を含めない。

ニコニコ動画専用、ChromeのDeveloper Modeでの個人利用を想定します。このリポジトリはPublicですが、Chrome Web Storeでの公開は前提としません。

## 開始方法

リポジトリ直下で以下を実行し、Chromeのデベロッパーモードから `.build/extension/` を読み込みます。

```sh
npm ci --ignore-scripts
npm run build
```

ツールバーのアイコンまたは視聴ページの「NicoPocketで保存」から独立ウィンドウを開きます。詳しい確認方法は開発ガイドを参照してください。表示される音質・AAC／JPEG別保存の選択は今後接続するM4A保存用であり、既存保存処理の設定を変更しません。

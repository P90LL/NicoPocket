# Phase 11: 音声合成キャラクターのArtistプリセット

## 目的と範囲

Artist / Album Artistへ、指定された音声合成キャラクター35件をJSONで追加した。最新のUI修正を含む状態から、指定ブランチ`codex/feature/metadata-edit`を作成した。コミット・プッシュは実行していない。

既存の検索付きチェックボックス選択画面、自由入力、1行1項目の下書き、共通Metadata正規化を再利用する。Series / Album、Genre、Date、Creation Timeには同梱キャラクターを追加しない。

## JSONと並び順

配置は`nico_downloader/pocket/presets/metadata-artists.json`。

```json
{
  "version": 1,
  "artists": ["初音ミク", "鏡音リン"]
}
```

上記は構造例。実ファイルは指定された全35件を収録している。表示名と保存値に同じ文字列を使用し、大文字小文字や別名への変換を行わない。ID・aliases等は今回導入しない。JSONのversionは同梱データ形式の番号であり、ユーザープリセットのバックアップversion 2とは独立する。

初音ミク、鏡音リン、鏡音レン、巡音ルカ、KAITO、MEIKO、重音テト、宮舞モカ、弦巻マキ、小春六花、夏色花梨、花隈千冬、結月ゆかり、紲星あかり、琴葉茜、琴葉葵、ずんだもん、東北きりたん、東北ずん子、東北イタコ、GUMI、音街ウナ、可不、星界、裏命、狐子、羽累、IA、ONE、さとうささら、すずきつづみ、四国めたん、春日部つむぎ、冥鳴ひまり、フリモメン。

同梱候補はJSON登録順。ユーザー登録候補がある場合はその順序を優先し、共通候補を後ろへ追加する。前後空白を除去した完全一致で重複を除く。

## 接続・状態

`metadata-presets.js`の`loadArtistCatalog()`が拡張機能内JSONを読み込み、既存の配列検証で型・件数・文字数を確認する。成功した一覧だけを画面の存続期間中キャッシュする。

`selectionPresets()`がユーザー登録値と同梱値を統合し、Artist / Album Artistの両方へ同じJSON一覧を提供する。storageへ自動登録・上書きしない。設定画面は編集画面と同じ統合候補を表示し、同梱値の編集・削除にも対応する。削除はArtist / Album Artist別の除外設定として保存し、同梱JSON本体は変更しない。JSON Import / Exportはユーザー登録値と除外設定を扱う。

チェックした値は親画面の下書きへ1行ずつ追加する。入力済みの行との比較はtrim後の完全一致で行い、手入力のスペースやカンマを分割しない。親画面の「適用」までは確定せず、「キャンセル」「自動取得値に戻す」「動画切り替え」は既存仕様を維持する。

例: 下書きの`宮舞モカ`と`弦巻マキ`は、プレビューと最終M4AのArtistで`宮舞モカ, 弦巻マキ`となる。自動取得された投稿者を置き換える場合は、入力欄を編集・空欄にしてからプリセットを選択する。

## 失敗時

JSONの取得失敗、HTTPエラー、不正JSON、未対応version、不正要素型では共通候補だけを省略し、短い案内を表示する。登録済みプリセット・自由入力・Metadata適用・Downloadを維持する。失敗をキャッシュせず、次回読み込みで再試行する。URL全文や取得データをログ出力しない。

## 設定画面への統合

- 一覧取得を`selectionPresets()`へ統一し、編集画面と設定画面で同じ候補を表示する。各一覧は高さ360px以内でスクロールし、既存追加欄は一覧の下に維持する。
- 同梱名の削除は`metadataPresets.excludedArtists`へArtist / Album Artist別に保存する。両配列を持つ任意項目として検証し、既存version 2でこの項目がないデータは従来どおり扱う。
- 同梱名の編集は旧名を除外し、新名をユーザー登録値として保存する。同名変更は何もしない。重複先への編集・追加は拒否する。
- 削除した名の再追加では該当グループの除外を解除する。設定更新は編集中の候補にも同期し、入力済みMetadata自体は自動変更しない。
- バックアップに除外設定を含める。除外項目のない旧JSONを読み込むと、置き換え後は同梱名が再表示される。

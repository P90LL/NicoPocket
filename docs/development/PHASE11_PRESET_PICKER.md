# Metadataプリセット選択画面

## 変更

Artist / Album Artist / Series / Albumのチップ一覧を、件数付きの「プリセットを選択」ボタンへ置き換えた。Metadata編集画面の上に検索付きの選択画面を開き、登録件数によって編集画面の高さが増えない構成とした。

- Artist / Album Artistはチェックボックスで複数選択。登録済みの値を追加・除外し、手入力の行は保持する。スペース・カンマで名前を分割しない。
- Series / Albumはラジオボタンで単一選択。未選択では現在の入力を保持する。
- 検索して候補が非表示になっても選択を保持する。候補一覧を独立してスクロールする。
- 「選択を反映」は親画面の下書きだけを更新する。選択画面のキャンセルは下書きを変更せず、親画面のキャンセルは従来どおり編集全体を破棄する。
- 4000文字超過時は選択画面を閉じず、選択を減らす案内を表示する。
- 編集中の設定変更を一覧へ反映する。削除済み候補の入力値は手入力として保持する。
- ネイティブdialogとinertで背面を遮断し、Tabを選択画面内に制限する。Escapeで選択画面だけを閉じ、起動ボタンへフォーカスを戻す。
- 動画切り替えでは両画面を閉じ、下書きの混入を防ぐ。

## 維持した仕様

Genreの標準・追加・カスタム入力仕様、プリセット保存形式、設定画面、Metadataマッピング、音質処理、Artwork、FFmpeg、M4A保存経路は変更していない。

- 手入力・名前内スペース・カンマの保持、重複追加防止、4000文字制限。
- 選択画面と親画面の適用・キャンセル、Tab循環、Escape、フォーカス復帰、設定変更の同期、SPA動画切り替え。

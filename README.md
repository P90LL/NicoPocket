# NicoPocket

ニコニコ動画のAAC音源を、編集したタイトル・Metadata・Artwork付きのM4Aとして保存する個人用途のChrome拡張機能です。

**個人利用・ローカルインストール専用です。Chrome Web Storeでの公開予定はありません。**

## About

[masteralice3104/nico_downloader](https://github.com/masteralice3104/nico_downloader)の動画情報・HLS/CMAF取得と同梱FFmpegを基礎にしています。高音質と192 kbps以下の音声は既存AACをM4Aへそのまま格納します。標準音質で取得音源が192 kbpsを超える場合はAAC 192 kbpsへ再エンコードします。

```text
動画ページ → NicoPocket編集 → Download
→ 既存音声取得 → 音声コピーまたは標準音質の192 kbps化
→ Metadata・Artwork付きM4A → 編集タイトル.m4a
```

## Features / Initial Scope

- [x] 独立したNicoPocket編集ウィンドウ
- [x] 動画情報・元タイトル・投稿者・サムネイルの取得
- [x] タイトル編集・禁則文字の正規化
- [x] 1:1固定Artworkクロップ・ドラッグ・ズーム・リセット
- [x] 標準音質 / 高音質の入力ストリーム選択
- [x] AAC取得・M4A remuxと標準音質の192 kbps上限化
- [x] Metadata・JPEG Artwork埋め込み
- [x] Metadataの保存前プレビュー・編集
- [x] Metadataプリセットの追加・編集・削除とJSONバックアップ
- [x] 取得進捗・生成・保存・完了・エラー表示
- [x] キャンセル・中断後の再試行・同一動画の連続保存
- [x] NicoPocketの名称・アイコン・使い方案内

複数サイト、一括・並列Download、キュー、MP3、AIクロップは対象外です。

### Title Edit

元動画タイトルを初期値として編集できます。禁則文字・空白・末尾の点等を共通関数で正規化し、空のタイトルは動画IDへ戻します。

保存名の拡張子を除いたタイトルと、M4Aの`metadata.title`は同じ値です。保存先に同名ファイルが存在するとChromeが連番を付ける場合があります。元タイトルは編集不可の参照欄に表示します。

### Artwork

固定正方形の枠に対して元画像を中央配置し、余白が出ない倍率からドラッグ・ズームで調整します。適用結果は**768×768 JPEG、品質0.9**です。JPEGを再変換せずattached pictureとして埋め込みます。

未編集時もサムネイルから中央クロップした768×768 JPEGを自動生成して埋め込みます。画像欠損・取得・生成失敗時のみArtworkなしで保存を継続します。同じ動画の編集状態はウィンドウ内で保持し、別動画で初期化します。ウィンドウを閉じた後の永続保存は行いません。

PNGも同梱FFmpegで格納・音声コピー・Metadata・画像バイト一致を検証済みですが、ネイティブプレイヤー比較が未確認のためJPEGを維持しています。

### Audio

高音質、標準音質の192 kbps以下、入力品質不明時はFFmpegの`-c:a copy`を使用します。標準音質で取得する入力が192 kbpsを超える場合だけ、同梱FFmpegの`-c:a aac -b:a 192k -profile:a aac_low`でAAC-LCへ再エンコードします。ビットレートを上げる処理は行いません。192 kbpsはエンコードの目標値で、実測平均値は音声内容・長さによって変わります。最終保存はM4A、Blob MIME typeは`audio/mp4`です。AACやJPEGの中間ファイルは保存しません。

### Audio Quality

初期値・別動画への切り替え時は標準音質です。

| 利用可能な候補 | 標準音質 | 高音質 |
| --- | --- | --- |
| 128 kbps | 128 | 128 |
| 128 / 192 | 192 | 192 |
| 128 / 192 / 256 | 192 | 256 |
| 256のみ | 192へ再エンコード | 256のまま |
| 品質不明 | 既存の既定取得 | 既存の既定取得 |

標準は192 kbps以下の最高品質を優先します。該当候補がなく192 kbps超を取得する場合は192 kbpsへ再エンコードします。高音質は最高bitrateを取得し、そのまま保存します。品質IDに明示されたkbpsを利用し、不明な値は推測せず従来の取得・音声コピーへ戻します。今回の仕様変更と検証は[PHASE11_AUDIO_192K.md](docs/development/PHASE11_AUDIO_192K.md)に記録しています。

### Metadata

UIとFFmpegが同じ生成関数を使用します。取得できた項目だけを設定します。

| 表示 | M4Aタグ / 入力 |
| --- | --- |
| Title | 編集・正規化済み`title` |
| Artist | 投稿者`artist` |
| Video ID | `episode_id` |
| Video URL | `comment` |
| Tags | 取得した動画タグを `, ` 区切りで保存する`keywords`（自動取得・編集不可） |
| Genre | `genre` |
| Series / Album | `album`、取得できる場合の`album_artist` |
| Date | 有効な投稿日時の`date` / `creation_time` |
| Artwork | 中央クロップまたは編集済みJPEGのattached picture |

保存前にDownloadボタン直下の「メタデータを編集」からArtist、Genre、Series / Album、Album Artistを編集できます。Artist / Album Artistは**1行1項目**で入力し、空行を除去・各行をtrimして、保存時に `, ` 区切りへ正規化します。名前内の半角・全角スペースは区切りとして扱いません。既存のカンマは名前の一部の可能性があるため自動分割しません。

Titleは既存の保存タイトルと共通です。Video ID / URL、Date / Creation Timeは読み取り専用です。編集項目を空欄にするとそのタグを省略します。「適用」でプレビューと保存値へ反映し、「キャンセル」で下書きを破棄します。「自動取得値に戻す」は下書きを現在動画の初期値へ戻し、適用時に確定します。

同一動画の再編集・再保存では適用値を保持し、別動画や別タブへ切り替えると初期化します。編集画面を閉じた後の永続保存は行いません。モーダル編集中は背面操作とDownloadを遮断します。

日時はコンテナ内でUTC表記になる場合があります。Descriptionはこの版では追加していません。実装・検証は[PHASE11_METADATA_EDIT.md](docs/development/PHASE11_METADATA_EDIT.md)に記録しています。

### Metadata Presets

Artist、Album Artist、Genre、Series / Albumをプリセットとして利用できます。メタデータ編集画面の「プリセットを管理」、または拡張機能のオプションから設定画面を開きます。

- Artist / Album Artistは「プリセットを選択」から検索付きの選択画面を開きます。チェックで追加・除外を切り替え、「選択を反映」で編集画面の下書きへ反映します。手入力値と名前内のスペースを維持し、入力済みの値を重複追加しません。保存時は既存どおり `, ` 区切りになります。
- Series / Albumは同じ選択画面で1件を選び、現在値を置き換えます。未選択・キャンセルの場合は現在値を維持します。自由入力も可能です。
- Artist、Album Artist、Albumの初期プリセットは空です。設定画面で追加・直接編集・確認後の削除ができ、登録順を維持します。前後の空白を除去して空文字・完全一致の重複を防ぎます。
- 選択画面は候補一覧だけをスクロールでき、検索しても選択状態を維持します。背面の編集画面は操作できません。Escapeは選択画面だけを閉じ、元のボタンへフォーカスを戻します。
- プリセットは下書きへの入力補助です。「適用」まで確定せず、「キャンセル」で破棄します。「自動取得値に戻す」は動画の初期値へ戻す操作で、登録済みプリセットやGenreの表示設定を変更しません。
- 設定変更は次回の編集画面表示時に読み込みます。編集中も候補を更新し、入力中の下書きは維持します。

#### Genre

Genreだけは「標準ジャンル」「追加ジャンル」「カスタム入力」に分かれ、保存値は1つの文字列です。

標準ジャンルは音楽・サウンド、VOCALOID、Synthesizer V、UTAU、歌ってみた、演奏してみた、ゲーム、アニメの8種類です。新規利用時はすべて有効です。固定IDで管理し、設定画面で表示ON／OFFを変更できます。標準ジャンル自体の編集・削除はできません。

追加ジャンルは登録順で表示し、追加・編集・確認後の削除ができます。標準ジャンルの表示名との完全一致も登録不可です（標準をOFFにしていても同様）。

Metadata編集画面は、有効な標準ジャンルと追加ジャンルをグループ別の選択欄に表示します。「カスタム入力」を選んだときだけ自由入力欄を表示します。カスタム値をプリセットへ自動登録しません。

元Genreが候補と一致すればその候補を選択し、一致しなければカスタム入力として元値を保持します。標準ジャンルをOFFにしていても動画の元Genreを削除しません。「自動取得値に戻す」でも同じ判定で元値を復元します。

#### JSONバックアップと移行

プリセットは`chrome.storage.local`の`metadataPresets`へ保存します。動画情報・配信URLを自動保存しません。「プリセットを書き出す」で`nicopocket-metadata-presets.json`を保存できます。現在のバックアップ形式はversion 2です。

```json
{
  "version": 2,
  "metadataPresets": {
    "artists": [],
    "albumArtists": [],
    "albums": [],
    "genres": {
      "enabledBuiltins": ["music-sound", "vocaloid", "synthesizer-v", "utau", "singing", "performance", "game", "anime"],
      "custom": []
    }
  }
}
```

「プリセットを読み込む」は形式を検証し、確認後に全項目を置き換えます。マージは行いません。キャンセル・不正JSON・未対応version・非文字列・未知の標準ID・標準名と重複する追加ジャンルがある場合は既存データを維持します。trim後の空文字と完全一致の重複を除去し、無関係なフィールドは保存しません。

旧storageとversion 1のJSONの`genres`配列は、標準名と一致する値を対応IDへ、それ以外を追加ジャンルへ移行します。旧設定の値だけを移行し、新しい標準候補を勝手に有効にしません。旧storageは初回読み込み時に新形式で保存します。

1項目は4000文字以内の1行、各一覧は1000件以内、読み込むJSONは1 MB以内です。バックアップには登録した値が含まれるため、共有前に内容を確認してください。初期プリセット実装は[PHASE11_METADATA_PRESETS.md](docs/development/PHASE11_METADATA_PRESETS.md)、現行Genre仕様は[PHASE11_METADATA_GENRE.md](docs/development/PHASE11_METADATA_GENRE.md)に記録しています。

### UI

UIはダークテーマ固定です。元ページの「NicoPocketで保存」から独立ウィンドウを開きます。タイトル・Artwork・音質を編集し、開閉式のMetadata欄で確認してDownloadを実行します。大きな音声取得はDownload押下後に開始します。

## Usage

1. Chromeで`chrome://extensions/`を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの **`nico_downloader/`** を選択します。
3. ニコニコ動画の動画ページを開き、動画を再生します。
4. 「NicoPocketで保存」を押します。
5. 保存タイトル、Artwork、音質、Metadataを確認します。必要に応じてArtworkやメタデータを編集して適用します。
6. Downloadを押します。Chromeの許可・保存先確認が表示された場合は、Chrome側で操作してください。
7. 中断・エラー後は再試行できます。待機中はキャンセルで解除できます。

拡張機能更新時は拡張機能を再読み込みし、開いている動画ページも再読み込みしてください。ツールバーのNicoPocketアイコンと「拡張機能のオプション」から使い方とプリセット管理を開けます。

保存形式・保存名の旧設定は表示しません。必要な既存取得設定は内部で維持し、新規利用時に必要な既定値を補います。

## Known Limitations

- Chromeの許可UIや保存先ダイアログは自動承認しません。Chrome側で確認してください。
- APIで保存先ダイアログを直接識別できない場合があります。保存待ち・保存中表示は取得できる状態に基づきます。待機中はキャンセルできます。
- 保存開始を60秒確認できない場合はタイムアウトします。Download ID取得後は完了・中断監視を利用し、編集画面が開いている間は5秒ごとに自分の保存を確認します。保存量が10分変化しない場合はタイムアウトします。取得処理全体には既存の30分上限もあります。
- 同種のニコニコ保存系拡張機能との同時利用は非推奨で、共存時の挙動は保証しません。無関係な保存要求を自動キャンセルしません。
- NicoPocketが所有する要求はジョブID・Blob URLで照合します。無関係なDownloadは変更しません。
- 長時間・大容量の動画はブラウザメモリや同梱FFmpegの制約を受けます。
- ニコニコ側の配信仕様、DOM、音質ID、画像ホストが変わると取得できなくなる場合があります。
- PNGの一般的なプレイヤー比較は未確認です。JPEGを維持しています。
- 編集画面を閉じるとArtwork編集状態は失われます。保存状態の確認・キャンセルには編集画面を使用してください。

## Troubleshooting

- **AACも保存される・プレーヤー設定が勝手に開く:** 同種の保存拡張機能を無効化し、動画タブを閉じて新しいタブで確認してください。実サイトでは別拡張「ニコニコ保存」の無効化で解消しました。
- **保存が進まない:** ChromeのDownload許可・保存先ダイアログを確認してください。待機をキャンセルした後に再試行できます。許可UIは自動操作しません。
- **更新が反映されない:** 拡張機能を再読み込みし、動画ページも再読み込みしてください。
- **動画・Artworkを取得できない:** 動画を再生して再試行してください。画像取得失敗時はArtworkなしで保存します。ニコニコ側仕様変更や実サイト固有の状態によって取得できない場合があります。

## Notes

個人用途の非公式ツールです。ニコニコ動画・ドワンゴ等の公式プロジェクトではありません。外部への診断ログ送信、解析、ストア配布は実装していません。

## Permissions

- `storage`: 設定、取得元情報、ジョブ・保存監視の状態を保持。
- `downloads`: 自分の保存の監視・照合・キャンセル。
- 画像取得ホスト: `nicovideo.cdn.nimg.jp`、既存画像の`tn.smilevideo.jp`。
- 動画ページ上のcontent script: `www.nicovideo.jp`。

`tabs`、`scripting`、全URLのhost permissionは要求しません。ニコニコ大百科用の旧content scriptは読み込み対象から外しました。
